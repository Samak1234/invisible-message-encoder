# Invisible Message Encoder

A beginner-friendly Python project that hides secret messages inside text using invisible Unicode characters.

## Features
- Encode messages into invisible characters.
- Decode hidden messages.
- Detect possible hidden messages in text.

## Technologies
- Python
- Unicode
- Binary encoding

## Status
🚧 In development.

## Goal
To learn Python, binary conversion, Unicode, and the basics of steganography.
